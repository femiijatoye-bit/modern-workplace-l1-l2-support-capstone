# Business Scenario

## Organization

**Company:** Northstar Creative Solutions  
**Industry:** Digital marketing and creative services  
**Company Size:** 25 users  
**Environment Type:** Cloud-first Microsoft 365 workplace

Northstar Creative Solutions is a fictional small business used for this Modern Workplace L1/L2 Support Capstone.

The company relies on Microsoft 365 and Windows endpoints for daily operations. The IT support function is responsible for user lifecycle management, endpoint administration, access control, troubleshooting, documentation, and security hygiene.

## IT Support Responsibilities

The simulated L1/L2 support function will be responsible for tasks such as:

- Creating and managing user accounts
- Managing groups and access
- Assigning Microsoft 365 licences
- Supporting onboarding, role changes, and offboarding
- Managing authentication and MFA
- Enrolling and administering Windows devices where licensing permits
- Applying device configuration and compliance policies
- Deploying applications where licensing permits
- Troubleshooting user, identity, application, and endpoint issues
- Documenting incidents and resolutions
- Escalating issues when appropriate
- Using least privilege for administrative tasks
- Using PowerShell for selected administrative and automation tasks

## Project Boundary

This is a simulated portfolio environment.

It is separate from all previous Active Directory, Azure, honeypot, SIEM, and help-desk labs.

Only technologies and configurations that are actually implemented and validated during this project will be documented as completed.
